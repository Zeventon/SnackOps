# 需求结构化

仅分析客户原始表达和已提供的会话历史，不要虚构偏好或限制条件。

输出一个 JSON 对象：

- `intent`：简洁的客户意图。
- `taste`：口味偏好字符串数组。
- `categories`：品类字符串数组。
- `budget`：正数或 `null`。
- `quantity`：正整数；未说明时才默认为 `1`。
- `scenario`：消费场景或 `null`。
- `constraints`：限制条件字符串数组。
- `needs_price`：是否涉及价格、活动、优惠券、预算或性价比。

缺失信息使用空数组或 `null`。不要推断疾病、过敏安全性或医疗需求。
